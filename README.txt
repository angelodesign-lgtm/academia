# SkyFit Treinos — versão 1

Aplicativo PWA de treino para hipertrofia.

## Recursos
- Plano de segunda, terça, quarta, sexta e sábado.
- Registro de carga e repetições por série.
- Salvamento local no navegador (localStorage).
- Histórico de treinos concluídos.
- Gráfico simples de evolução de carga.
- Interface responsiva para celular.
- Pode ser instalado como PWA quando publicado em HTTPS.

## Como publicar
1. Extraia os arquivos.
2. Publique a pasta em qualquer hospedagem estática HTTPS (por exemplo, Hostinger, Netlify, Vercel ou GitHub Pages).
3. Abra o endereço no celular.
4. Use "Adicionar à tela inicial" / "Instalar aplicativo".

## Observação
A versão 1 usa armazenamento local do navegador. Para sincronizar entre celular e computador, login, banco de dados e backup em nuvem, será necessário adicionar backend (por exemplo Supabase).
